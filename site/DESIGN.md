# TaskDock site: design system

Approved at the gate (2026-11-09) with one change from the author: **copy Intercom's typography, colors, accent, image type, tones and transitions in full**. Sources:
**[I]** intercom.com/helpdesk, computed styles measured 2026-11-09 at 1440×900 and 390×844 · **[R1–R3]** the three glass reference images · **[TD]** the TaskDock app (`Theme.swift`, `Picker.swift`, `scripts/icon.swift`).

## Direction

**Job:** a developer or hiring reader decides "this is a real, carefully built tool" → it must never feel like a SaaS template or a concept shot of software that doesn't exist.

**Moods:** exact (not clinical) · calm (not empty) · tactile (not decorative).

**Non-goals:** no invented stats, logos, testimonials or quotes · no Intercom copy, logo, illustrations, art files or font files · no dark mode or theme toggle · no scroll-jacking, parallax or auto-playing motion · no animated blur · no generic feature-card grid.

## What is copied from Intercom, and what can't be

| Copied exactly [I] | Not copyable, so matched instead |
|---|---|
| Palette, accent, ink tones, opacities | **Fonts.** Saans, Serrif and SaansMono are commercial and licensed to Intercom. Metrics (size, weight, line height, tracking) are copied; the faces are the closest OFL fonts: Geist 400, Newsreader 300, DM Mono 400 (DM Mono is the mono Intercom itself loads). |
| Type scale, weights, line heights, tracking | **Art.** Intercom's blue fibre swirls are their artwork. The page uses original procedural art of the same type (fine fibre ribbon in Intercom's blue range), generated by `.context/tools/swirl.mjs`. |
| Section rhythm, container, borders, buttons, index list, underline links, footer labels | |
| Transition properties, durations and curves | |

| Token | Value | Use |

| `--white` | `#FFFFFF` | Hero, white bands, nav |
| `--paper` | `rgb(250 249 246)` | Alternating warm bands |

| `--stone` | `rgb(211 206 198)` | 1px value-box borders, hairlines, registration squares |
| `--ink` | `#111111` | Text |
| `--ink-80/70/60/50` | `rgb(17 17 17 / .8 .7 .6 .5)` | Body grey (.7, .8), second tone of headlines (.6), inactive index items (.5; Intercom uses .4, raised to hold 3:1 on large text) |

TaskDock's own blue `#2B6BF2` and note orange appear only inside the app recreations, because they are the app's real colors.

## Layout [I]

- Container 1170px, 135px side margins at 1440; 20px gutter on mobile. Nav 66px, white, sticky.
- Section padding 80px top and bottom (56px on mobile). Bands alternate white and warm paper.
- Value boxes: three columns, 15px gap, 1px stone border, 16px padding, 240px tall, title top, serif body bottom.
- Feature sections: eyebrow, two-tone H2 and serif lead (≤520px), then a full-width inset panel with art and product, then three items with 8px accent bullets.
- Showcase: list left (active item ink, accent bullet, 64×2px accent line on top), panel right.
- Index: card left, 54px list right with stone hairlines; hover or focus turns an item ink with ↗.
- Registration squares: 5px stone squares at band corners.
- Closing call to action: centred H2 and buttons over a dot grid with small art tiles.

## Buttons and links [I]

- 14px, 40px tall (44px on touch), 12px side padding, 4px radius. Solid: ink, hovers to accent. Line: 1px ink, hovers to ink fill.
- Underline links: 0.8px `background-image` underline, retracts on hover, `background-size 200ms ease-out`.
- Focus: 2px accent outline, 2px offset.

## Motion (emilkowalski/skills, design-engineering harness)

Revised 2026-11-09 at the author's request: Intercom's curve `cubic-bezier(.4,0,.2,1)` is replaced, because the harness forbids it.

| Use | Value |
|---|---|
| Enter, feedback | `cubic-bezier(.23,1,.32,1)` (strong ease-out) |
| On-screen movement (Dock icons) | `cubic-bezier(.77,0,.175,1)`, 250ms, View Transitions |
| Color and background | `ease`, 150ms |
| Press | `scale(.96)`, 160ms ease-out, on every button |
| Picker opened by pointer | settle from `scale(.97)` 250ms, rows fade up 4px over 200ms, 30ms stagger |
| Showcase step by click | 200ms crossfade with a 6px settle; exit 150ms |

- **Keyboard-initiated changes never animate**: typing, arrow keys, ↩ and esc in the demo, and arrow keys in the showcase.
- **No scroll reveals.** Every section renders at once.
- Hover styles live behind `@media (hover: hover) and (pointer: fine)`.
- Only transform, opacity, color and background animate. No `transition: all`.
- `prefers-reduced-motion`: movement goes (`--motion-scale: 0`, no View Transition move), fades stay.

## Restraint

Removed as non-essential: registration squares, hero corner labels, dot-matrix tiles, invented UI tiles in the agent showcase, the closing dot grid and art tiles, and labels sitting on the art. Honesty notes ("illustration", "examples") moved to one plain caption under each panel.

## Glass (from R1–R3 and the app)

Glass is used only for TaskDock's own UI, which really is macOS material: the picker shell, Dock, menu bar, banner and tiles. Recipe: `rgb(242 242 244 / .66)`, `backdrop-filter: blur(30px) saturate(180%)`, 1px `rgb(0 0 0 / .1)` border, `0 8px 16px rgb(0 0 0 / .12)` shadow, top inner highlight. The blue art behind it is what makes the material read [R2]. Radii come from the app: shell 24, cards 18, rows 12, chips 7 and 9, tiles 28 [R1]. Fallback without `backdrop-filter`, or with `prefers-reduced-transparency`: solid `rgb(244 244 246)`.

## App recreations [TD]

The picker demo mirrors `Picker.swift`: widths 320 (pill) and 480 (open), 6px rim, 46px search card, 38px rows, 11px section labels, the app's UI strings verbatim (sample template names are the page's own: the app's sample data uses em dashes, which the copy rules forbid). Section-label grey is `#616161` instead of the app's `#737373` so it holds 4.5:1 on glass. Real app icons (extracted from the installed apps with `NSWorkspace`) appear in the Dock, the resume chips and the Works-with list. The Dock has no labels, like the real one.
